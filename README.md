Sales & Business Performance Dashboard – Power BI

Project Overview

This project is an interactive Power BI dashboard designed to analyze sales performance, financial results, operational performance, and customer-related metrics.

The dashboard provides different views for management to monitor key business KPIs and identify performance trends across products, regions, countries, store types, and customer segments.

Dashboard Pages

1. CEO Dashboard

This page provides a high-level overview of business performance to support executive decision-making, including:

- Sales by Store Type
- Sum of Quantity by Category
- Total Profit by Country
- Key business performance indicators

2. Operations Dashboard

This page provides an overview of operational performance, including:

- Total Profit
- Orders by Category
- Total Orders by Region
- Total Orders by Store Type
- Sales Performance by Customer Segment

3. Financial Dashboard

This page focuses on the company's financial performance, including:

- Total Sales
- Total Costs
- Discount Value
- Total Profit
- Total Orders
